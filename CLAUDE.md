# Project workflow

Before writing code:

1. Read docs/Kế-hoạch-triển-khai-quản-lí-thư-viện-và-đọc-sách.md
2. Read docs/SYSTEM_ARCHITECTURE.md
3. Compare existing GitHub Issues.
4. Never create duplicate Issues.
5. Every new feature must become a GitHub Issue.
6. Add every Issue to the GitHub Project:
   "Library Management Reading System"
7. New Issues start in Backlog.
8. When implementation starts:
   Status -> In Progress.
9. When Pull Request is opened:
   Status -> In Review.
10. When merged:
    Status -> Done.
